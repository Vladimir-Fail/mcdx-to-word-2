# Экспорт формул из Mathcad 15 в Word

Программа `mathcad_word.py` читает файлы Mathcad 15 (`.xmcd`) и экспортирует
формулы в документ Word с шаблоном стилей. Есть графический интерфейс (tkinter)
с drag-and-drop выбором входного файла и шаблона.

## Возможности
- Настройка количества значащих цифр при округлении чисел.
- Комплексные числа автоматически переводятся в полярную форму `|z|∠φ°`
  (поддерживается мнимая единица как `j`, так и `i`).
- Замена экспоненциальной записи угла `e^(1j·deg·φ)` на `∠φ°`
  (при отсутствии множителя перед конструкцией добавляется `1`: `1∠30°`).
- Экспорт матриц (включая комплексные элементы в ячейках, разбиение широких
  матриц на несколько блоков).

## Установка и запуск
```bash
pip install pypandoc tkinterdnd2   # tkinterdnd2 — опционально (drag-and-drop)
# требуется установленный pandoc: https://pandoc.org/installing.html
python mathcad_word.py
```

## Структура репозитория
- `mathcad_word.py` — основная программа.
- `проверка/` — тестовые файлы Mathcad (матрицы: `ЭМПП_ТР2 — копия.xmcd`;
  комплексные числа и углы: `к лр1.xmcd` и др.).
- `шаблон/Шаблон стилей.docx` — шаблон стилей Word.
- `старые/` — легаси-версии скриптов (не использовать).
- `agents.md` — описание проекта, принципы экспорта и правила работы
  для AI-ассистентов (Qwen Coder и аналогов).

## Разработка
Подробные принципы разбора Mathcad → LaTeX → Word описаны в `agents.md`.
После изменений проверяйте компиляцию (`python -m py_compile mathcad_word.py`)
и регрессию на файлах из `проверка/`: матрицы, полярная запись ∠, j/i,
обычные степени.
